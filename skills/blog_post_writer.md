# Blog Post Writer

A framework for writing clear, engaging, and well-structured blog posts.

## Step 1: Clarify the Core
- **Topic**: What is this post about?
- **Angle**: What's your unique take? What problem does it solve?
- **Target reader**: Who are you writing for? What do they already know?

## Step 2: Outline
- **Working title**: Clear and benefit-driven.
- **Introduction**: Hook the reader, state the problem, and preview the post.
- **Body sections**: 3-5 main points. Each gets its own section with a heading.
- **Conclusion**: Summarize key takeaways and end with a call to action.

## Step 3: Write the First Draft
- Don't edit while writing. Get it all down.
- Use short paragraphs (2-3 sentences).
- Write like you're talking to a friend — conversational but professional.
- Include examples, stories, or analogies to illustrate points.

## Step 4: Add Structure
- Use headings and subheadings to break up text.
- Use bullet points or numbered lists for steps or multiple items.
- Bold key phrases for scannability.
- Include code blocks, screenshots, or diagrams where helpful.

## Step 5: Polish
- **Hook**: Does the opening grab attention? Rewrite if needed.
- **Flow**: Do transitions between sections feel natural?
- **Clarity**: Is every sentence clear? Cut jargon and filler.
- **Length**: Is it the right length for the topic? Don't pad.

## Step 6: SEO Basics (Optional)
- Include the main keyword in the title, first paragraph, and at least one heading.
- Write a compelling meta description.
- Use descriptive alt text for images.

## Step 7: Final Checklist
- Proofread for typos and grammar.
- Check all links work.
- Add a call to action (comment, share, subscribe, read more).
- Format for readability (line spacing, font, etc.).
